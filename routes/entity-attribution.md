# Entity Attribution

주소가 거래소, 브리지, VASP 또는 특정 프로토콜에 속하는지 검증한다.

## Flow

1. 온체인 활동에서 주소의 역할과 거래 패턴을 먼저 확인한다.
2. Explorer와 데이터 제공자의 라벨은 후보로만 사용한다.
3. 공식 문서, 공식 입출금 주소, 컨트랙트 배포 관계 또는 별도 데이터 소스로
   교차 검증한다.
4. 식별 근거와 신뢰도를 함께 기록한다.

```text
confirmed:
high confidence:
candidate:
```

서로 복사한 것으로 보이는 라벨 여러 개를 독립적인 근거로 세지 않는다. 소유자와
서비스 이용자를 구분하고, 근거가 부족하면 후보 상태로 남긴다.
